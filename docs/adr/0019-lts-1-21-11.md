# 0019. 1.21.11 is a long-term version

Date: 2026-10-01
Status: Accepted (amends ADR 0002)

## Context

ADR 0002 made 1.20.1 and 1.21.1 mandatory and everything newer best-effort.
1.21.11 is the last 1.21 release before the 26.x version scheme, so modpacks
and players settle on it the way they did on 1.20.1 and 1.21.1. The pack
already carries fixes specific to it (wall torch billboards, cloud alpha),
which only stay fixed if someone checks them.

## Decision

1.21.11 joins 1.20.1 and 1.21.1 as a mandatory version, tested in-game before
every release. 1.21.2 – 1.21.10, 26.x and all other versions stay best-effort.

## Consequences

- Three in-game checks per release instead of two.
- Version-specific code for 1.21.11 is held to the same bar as for 1.20.1 and
  1.21.1.
- The README, which is also the Modrinth page, names the three versions.
